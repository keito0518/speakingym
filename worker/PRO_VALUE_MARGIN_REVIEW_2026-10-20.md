# Speakingym 680円 Pro 採算・有料価値レビュー（2026-10-20）

**ステータス：試算のみ、月680円で利益が出るという検証は未完了。LIVE実課金はNO-GO。**

## 現行サービスで確認できたこと

- Free：**1日5 AIセッション**、各セッション最大20ターン（7分の制限も存在）、AI先生の講評は**1日3回**。
- Pro：**月600 AIターン**（600セッションではない）、AI先生の講評は**月100回**。セッション数の**日次上限がない**一方、セッション毎の時間・ターン上限は共通。利用枠はJST暦月初日に更新し、課金サイクルは契約日基準。
- 理論上、Freeを30日間毎日最大限使えば **150セッション × 最大20ターン = 3,000ターン相当**／講評**90回**。ただし7分・Gemini提供能力・実際の習慣により達成できるとは限らず、実測や予想平均ではない。
- したがって **「Proは必ずFreeより総会話量が多い」は虚偽になり得る**。Proの現状の違いは「忙しい平日は使わず週末にまとめて練習」「講評を日ごとの3回制限なしに集中活用」する柔軟性。Freeの30日理論最大講評90回に対してProは100回なので、講評総量の差だけでも弱い。
- `plans.html` にこの事実を誤認なく追記。**金額・Free/Pro利用制限・既存UIの購買ゲートは変更していない**。

## 公式公開レート（2026-10-20確認）と仮定

- Google Gemini `gemini-3.5-flash-lite` Standard: 入力 **$0.30 / 100万tokens**、出力 **$2.50 / 100万tokens**（thinking含む）。実際のWorkersモデル `worker/cost-telemetry.js` と一致。https://ai.google.dev/gemini-api/docs/pricing
- Stripe 日本標準: カード決済 **3.6%** と Billing 従量 **0.7%**、両方適用の仮定 **4.3% = 680円のうち29.24円**。アカウント契約内容・海外カード/為替等で差がある。https://stripe.com/jp/pricing ; https://stripe.com/jp/billing/pricing
- 為替は **160円/USDとする感度分析の仮定**。実際の為替・Google請求額ではない。
- Pro会員が月600 AIリクエスト＋講評100回を使い切るケースで試算。失敗/再試行による超過、Free負担、税務、Cloudflare、返金や人件費は**別途**。
- 月額税込680円でも、納める消費税は販売者の課税状況に依存する。**税相当61.82円の引当は感度分析用であり、実際の納付額ではない**。

## 無料会員が加わるとどうなるか（架空の人数・利用回数）

月100人がProを両上限まで使用、月500人がFreeをそれぞれ20回のAI会話、5回の講評に利用すると仮定。**無料会員の平均使用量を確認したわけではない**。

- 標準想定：Free1人のGemini仮原価 **5.752円/月**。Pro100人のStripe・Gemini控除後残額 51,220円 − Free500人原価2,876円 = **約48,344円/月**（**税・ホスティング・人件費・返金控除前**）。
- 高負荷想定：Free1人のGemini仮原価 **23.28円/月**。Pro100人残額596円 − Free500人原価11,640円 = **約−11,044円/月**（**税・ホスティング等控除前**）。
- Free1人が大きく使用すると、負担はさらに増加。上記の20回/5回は例示であって、事実や安全側の上限ではない。
- 原価検証ができないまま「月680円で常に黒字」とは主張できない。

## 実行できるローカル試算ツール

`node scripts/pro680-economics.mjs` は、**会員人数を仮定で1人／0人にしている**（現状の会員数を装わない）。引数で明示的に前提を変える。

```bash
node scripts/pro680-economics.mjs --scenario standard --fx 160 --pro-users 100 --free-users 500 --free-conv 20 --free-teacher 5
node scripts/pro680-economics.mjs --scenario heavy --fx 160 --pro-users 100 --free-users 500 --free-conv 20 --free-teacher 5 --tax-reserve 61.82
node scripts/pro680-economics.mjs --scenario standard --pro-users 50 --free-users 1000 --free-conv 40 --free-teacher 10 --retry-factor 1.2 --hosting 2000
```

- 許可された価格/上限以上のProの**成功使用枠**を指定するとfail closed。エラー/リトライによるGemini請求を `--retry-factor` として別途仮定できる。実際の料金・契約上限は変更しない。
- `scripts/ai-cost-report.mjs` は Cloudflareの個人情報を省いた実ログを分析する既存機能。**ログなし**では採算確認は不可能。本試算ツールのサンプルを実測と混ぜない。
