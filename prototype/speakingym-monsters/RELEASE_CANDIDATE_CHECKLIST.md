# Speakingym Monsters — 無料版の正式公開候補チェックリスト（2026-11-01）

## 方針
正式公開を早めるため、既存の森4エリア＋街4エリアを最初の無料公開範囲に固定する。まず「短い英語チャレンジ → 弱点攻撃 → 仲間の成長 → 次の冒険」の楽しさ・明快さを磨く。新エリアの大量追加、課金、外部AI採点は公開後の別マイルストーンとする。

## 直近のゲーム性仕上げ
- [x] 問題を出す前に攻撃タイプを確定させる。選んだ後は同じ問題をすり替えない。
- [x] 敵の弱点を日本語で明示し、該当する攻撃ボタン自体を強調する。
- [x] 自力正解の1回目からCHAINの手応えを見せる。既存のコンボ・必殺技・敵の反撃ルールを維持する。
- [x] 手作業で確認した自然な言い換えを追加する。反対の意思や重要条件の欠落を正解にしない。
- [x] 育成・進化の図鑑表示、セーブのコピー／復元、iPhoneのキーボード音声入力導線を維持する。

## 無料公開前のGO / NO-GO
- [ ] **最新コミットで**教材/戦闘Nodeテスト、Chromium/WebKitスマホ画面テスト、Launch回帰テストがすべて成功。
- [ ] **実機iPhone**（LINEアプリ内ブラウザとSafari）で、ボス前のリスニングからスピーキングに進み、英語キーボードの音声入力で英文が入力されることを確認。マイクが使えない場合も手入力で続行可能。WebKit自動テストだけでは合格としない。
- [ ] 1章の最初からボスまで、ヒント・誤答2回・敵反撃・進化した仲間・再読み込み後の図鑑を人が通しで確認。
- [ ] 旧プレビューURLに残るセーブの移行について案内を整える。固定URLの進捗は自動同期されず、別ブラウザ間はバックアップ操作が必要と明記する。
- [ ] プライバシー・録音/音声認識の説明、問い合わせ先、利用条件、アクセシビリティ表記を公開ページ上で確認。
- [ ] 公開先URL・無料範囲・公開日をユーザーが確認し、**本番変更とPRマージを明示承認**する。

## 課金版は別ゲート
PR #62のStripe TEST購入→権利付与→更新/失敗復旧→解約の実環境確認、staging Worker/D1構成、法的表示/原価検証が未完了。無料Monstersの早期公開と同時にStripe Live、既存契約、AIの本番課金設定を切り替えない。
